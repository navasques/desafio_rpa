# desafio_rpa
RPA Dev BTime - Teste Técnico

Este projeto demonstra coleta de dados via **API** e **Web Scraping**.  
O tema escolhido foi **cotações de moedas (USD/BRL, EUR/BRL)**.

---

## 🚀 Tecnologias
- Python 3.10+
- Requests
- Selenium / Selenium Webdriver
- Pandas

---

## 📦 Instalação
Clone o repositório e instale as dependências:

```bash
git clone https://github.com/navasques/desafio_rpa.git
cd desafio_rpa
pip install -r requirements.txt
```

---

## 📄 Saída
O script gera um arquivo CSV com os valores atualizados das moedas DOLAR AMERICANO, EURO, BITCOIN, YUAN e IENE
